# J&M Lavados

Plataforma web desarrollada para fortalecer la presencia digital de una empresa de servicios de limpieza y facilitar la captación de clientes.

## Características

- Diseño responsive
- Optimización para dispositivos móviles
- Información clara de servicios
- Canales de contacto
- Experiencia de usuario optimizada
- Despliegue en Vercel

## Tecnologías

- HTML5
- CSS3
- JavaScript
- TypeScript
- Git
- GitHub
- Vercel

## Objetivo

Desarrollar una solución web profesional que permitiera mejorar la visibilidad digital del negocio y facilitar el contacto con clientes potenciales.
